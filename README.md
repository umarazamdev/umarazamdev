## About Me

I am **Umar Azam**, a **BS Computer Science student (5th Semester)** at the **University of the Punjab, Gujranwala Campus**, and the **Co-Founder & Product Lead** at **[Hantalyze](https://hantalyze.com/)**.

At Hantalyze, I bridge product vision and technical engineering — leading product planning, software architecture, mobile and web development, UX decisions, and end-to-end product delivery.

My engineering core revolves around cross-platform mobile app development with **React Native** alongside full-stack web platforms using **React**, **Next.js**, **TypeScript**, **Node.js**, **Express**, **MongoDB**, and **Tailwind CSS**. I completed my formal Mobile App Development Internship at **Technic Mentors** in September 2026.

I integrate modern **AI-assisted engineering workflows** — utilizing CLI tools, AI agents, and model context workflows (such as **Claude Code**, **Codex CLI**, **Gemini CLI**, **OpenCode**, and **Cursor**) for accelerated software research, architecture planning, code reviews, and rapid debugging.

## Featured Projects

### 📱 Dukanlo — POS App for Shopkeepers *(IN DEVELOPMENT)*
> **Modern Point-of-Sale Solution for Pakistani Retailers**

Built with **React Native**, **Supabase**, **TypeScript**, and **ESC/POS Printer Integrations**.

- **Authentication & Security:** Implemented secure authentication with Supabase and Email OTP workflows.
- **Retail Operations:** Engineered POS workflows for shop management, inventory billing, and item cataloging.
- **Hardware Integration:** Integrated direct 58mm Bluetooth ESC/POS thermal printer receipt printing.
- **Platform:** Native Android builds optimized for handheld shopkeeper devices.

<br>

### 🛒 SmartMart — Mobile Marketplace App
> **Full-Stack Android Marketplace Application**

Built with **React Native**, **TypeScript**, **Node.js**, **Express**, and **MongoDB**.

- **Core Architecture:** Role-Based Access Control (RBAC) and multi-method authentication (JWT / Google / OTP).
- **Commerce Features:** Product variants, cart management, checkout workflows, coupons, and order tracking.
- **Analytics & Admin:** Custom dashboards for seller payout calculations and admin moderation controls.
- **Quality & CI/CD:** Backed by automated testing (**Jest** & **Supertest**) and automated **GitHub Actions CI** pipelines for signed APK builds.

🔗 **[Download Android APK (v1)](https://tinyurl.com/smartmartv1)**

<br>

### 🏫 APS School & College Kharian (GAK Website)
> **Responsive Educational Web Platform & Admin System**

Built with **React**, **TypeScript**, **Vite**, **Tailwind CSS**, and **shadcn/ui**.

- **Full-Stack Web Architecture:** Responsive multi-page web platform engineered for an educational institution.
- **Role-Based Admin Dashboard:** Integrated authentication system with custom admin portal for content management.
- **Interactive UI Components:** Custom Hero image sliders, animated statistic counters, and real-time news ticker.

🔗 **[Visit Live Website](https://gakwebsite.netlify.app/)**

<br>

### 💊 Pharmacy POS & SaaS Platform
> **Multi-Tenant Pharmacy Inventory & Sales Management**

Built with **React Native**, **Node.js**, **Express.js**, and **MongoDB**.

- **Multi-Tenant Architecture:** Built role-based access permissions, tenant isolation, and SaaS subscription tier logic.
- **Operations & Management:** Stock level tracking, purchase order management, supplier registries, customer invoicing, and revenue records.
