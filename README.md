## About Me

I am a **BS Computer Science student (5th Semester)** at the **University of the Punjab, Gujranwala Campus**, and a **Mobile App & Web Developer**. I completed my mobile app development internship at **Technic Mentors**, Gujranwala in September 2026.

I specialize in building both **cross-platform mobile applications** and **modern responsive web platforms**. My technical expertise covers **React Native (Bare CLI)**, **React.js**, **TypeScript**, **Node.js**, **Express.js**, **MongoDB**, **Tailwind CSS**, and **shadcn-ui**.

My work spans from shipping production mobile apps like **[SmartMart](https://tinyurl.com/smartmartv1)** (Mobile Marketplace) to engineering full-fledged web platforms like **[APS School & College Kharian (GAK Website)](https://gakwebsite.netlify.app/)** equipped with role-based admin dashboards, authentication systems, and live interactive UI components.

## Featured Projects

### 🛒 SmartMart — Mobile Marketplace App
> **Full-Stack Android Marketplace Application**

Built with **React Native**, **TypeScript**, **Node.js**, **Express**, and **MongoDB**.

- **Core Architecture:** Implemented Role-Based Access Control (RBAC) and multi-method authentication (JWT / Google / OTP).
- **Commerce Features:** Cart management, checkout workflows, and real-time order tracking.
- **Analytics:** Designed custom dashboards for seller payout calculations and admin moderation controls.
- **Quality & CI/CD:** Backed by automated testing suite (**Jest** & **Supertest**) and automated **GitHub Actions CI** pipelines for deploying signed Android APK builds.

🔗 **[Download Android APK (v1)](https://tinyurl.com/smartmartv1)**

<br>

### 🏫 APS School & College Kharian (GAK Website)
> **Responsive Educational Web Platform & Admin System**

Built with **React**, **TypeScript**, **Vite**, **Tailwind CSS**, and **shadcn/ui**.

- **Full-Stack Web Architecture:** Designed and developed an 8-page responsive web application tailored for an educational institution.
- **Role-Based Admin Dashboard:** Integrated authentication system with a custom admin portal for content management.
- **Interactive UI Components:** Built custom Hero image sliders, animated statistic counters, and a real-time live news ticker.

🔗 **[Visit Live Website (GAK Website)](https://gakwebsite.netlify.app/)**

<br>

### 🍔 FoodOnRoute — Food Delivery App
> **Location-Based Food Delivery Web Concept**

Built with **React**, **TypeScript**, **Vite**, **Zustand**, **React Map GL**, and **Framer Motion**.

- Food delivery concept app enabling ordering to current or future GPS coordinates.
- Features nearby restaurant discovery, map pin drops, order tracking, and fluid animated UI interactions.

<br>
